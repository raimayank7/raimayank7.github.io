How to use it

  1. Choose the state where the branch is, then the bank, then the branch.
  2. Copy bank details puts the bank, branch, IFSC code, MICR code and address in one block, ready to paste in a form or a message.
  3. Share on WhatsApp sends the same block with a link to the page, so the other person can check it.

Questions

What is on a branch page?

The IFSC code and MICR code of the branch, its address, the district and post offices of its PIN code, the payment services listed for it, other banks in the same PIN code, the same bank's other branches in the town and, where the bank merged, the earlier code of the branch.

How do I find a branch?

Choose the state, then the bank, then the branch. If you already have a code, type it in the code checker of IFSC by ShareYourGroup: it opens the branch.

Does every branch have a page?

Almost every one. A branch whose entry in the list has no usable address has no page of its own; its code is still in the lists and the checker.

Is it free?

Yes. There is no login and no limit.
